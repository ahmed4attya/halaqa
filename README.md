# حَلَقة (HALAQA)
منصة عربية سيادية للمجتمعات والأكاديميات المدفوعة، مبنية فوق نواة burhan-platform (https://github.com/Ibrahem3/burhan-platform) — ولقطاع الإطلاق الأول: المؤسسات الإسلامية والمراكز (مراكز تحفيظ، جمعيات، مدربون شرعيون).
## لماذا نبني هذا — إعلان نوايا
نبني بأسلوب هيبوقراطي صريح: نعلن ما نبنيه ولماذا، قبل أن ننجزه.
- المشكلة: منصات المجتمعات العالمية (Skool بـ$99/شهر، Circle بـ$89–199/شهر) ترتفع أسعارها ولا تفهم العربية: لا RTL أصيل، لا مدى ولا STC Pay، لا تسعير ريالي، لا امتثال PDPL.
- حلنا: «سكل العربي» — مجتمع + دورات بمدفوعات محلية (Moyasar)، بعربية أصيلة من اليمين لليسار، وتسعير ريالي (99–499 ريال/شهر)، وامتثال PDPL من اليوم الأول.
- لماذا مفتوح المصدر (AGPL-3.0): لأن الثقة تُبنى بالشفافية، ولأن دخلنا يأتي من الاستضافة والدعم وباقة المؤسسات — لا من إغلاق الكود عن أصحاب المراكز.
- روح «الاستخراج لا التجميد»: كل وحدة عامة نبنيها تُصمم قابلة للرفع كتحسين لنواة بُرهان نفسها.
## النواة التقنية
Nuxt 4 + Supabase (PostgreSQL + RLS تعدد مستأجرين) + Nitro على Cloudflare Pages + PWA. أصل النواة ونطاق النقل موثقان في SOURCE.md.
